# Tabata 間歇訓練 Web App (塔巴塔運動計時器)

這是一個專為「4 分鐘 Tabata 高強度間歇運動」打造的現代化響應式 Web 應用程式。

## 🌟 核心功能特色

1. **精準 Tabata 循環結構**：
   - 準備時間（預設 10 秒）
   - 衝刺運動（預設 20 秒，紅/黃高能量視覺）
   - 間歇休息（預設 10 秒，藍色冷卻視覺）
   - 8 組循環（標準 4 分鐘），附帶即時組數進度指示點。
2. **免外掛音效合成 (Web Audio API)**：
   - 內建瀏覽器原生合成音，倒數 3、2、1 短蜂鳴，切換階段發出雙重高音提示。
3. **語音即時報讀 (Web Speech API)**：
   - 語音提醒「開始運動」、「休息十秒」、「第 X 組，衝刺！」。
4. **手機運動優化體驗**：
   - **螢幕防休眠 (Screen Wake Lock API)**：運動過程手機螢幕保持常亮，不用中途伸手觸碰。
   - **觸覺震動 (Vibration API)**：在支援震動的手機上倒數與切換時自動震動提示。
   - **PWA (Progressive Web App)**：支援「加到主畫面」，像原生 App 一樣全螢幕啟動。
5. **高度自訂彈性**：
   - 點擊齒輪圖示可自訂「準備時間」、「運動時間」、「休息時間」與「總組數」，適合進階 HIIT 或初學者調降難度。

---

## 🚀 如何使用

### 1. 本地直接開啟
在任何電腦或手機瀏覽器中，直接雙擊或用瀏覽器開啟 `index.html` 即可使用。

### 2. 免費部署到網路上（讓手機隨時隨地開啟）
- **GitHub Pages**：將 `tabata-app` 資料夾推送到 GitHub 倉庫，到 Settings -> Pages 啟用，即可獲得免費的 `https://your-name.github.io/tabata-app/` 網址。
- **Vercel / Netlify**：直接把此資料夾拖拉到 Netlify Drop 或 Vercel 即可 10 秒完成部署。
- **加入手機主畫面**：
  - **iPhone (Safari)**：點擊底部分享按鈕 -> 選擇「加入主畫面」。
  - **Android (Chrome)**：點擊右上角選單 -> 選擇「安裝應用程式」或「加到主畫面」。
